# 🎲 주사위 확률 게임

## 활동 이름표 (선생님과 정한 이름 · 화면·슬라이드·대화에서 이 이름으로 불러요)
| 이름 | 무엇 | 화면 |
|---|---|---|
| **활동 1 · 칩 예측** | 반 전체가 같은 굴림에 칩을 놓고 겹친 만큼 점수 (1·6·60·600·6000번) | 교사 🪙 칩 예측 탭 |
| **활동 2 · 눈 대결** | 1:1, 주사위 한 개의 눈(1~6), 12·18번 | 교사 ⚔ 눈·합 대결 탭 (단계 1) |
| **활동 3 · 합 대결** | 1:1, 두 주사위의 합(1~12), 33·22번 | 교사 ⚔ 눈·합 대결 탭 (단계 2) |
| **모의실험** | 전략끼리 같은 굴림으로 1~1000판 겨루기 | 교사 🔬 탭 |

| **생각 모으기** | 질문을 학생 패드로 보내고 답을 슬라이드에 모으기 | 슬라이드 ❓ 장 |
| **학생 화면 보기** | 교사 학생 목록 👀 | 교사 화면 |

칩 예측 칩 놓기 화면에는 **대표 전략 모양** 5가지 그림(참고용). 대결 안의 기능: **전략 고르기**(🧭, 그림을 눌러 골라요) · **놓친 주사위**(빨간 ✖) · **포인트**(💰) · **자동 굴리기**(⚡). 코드에서는 `DC.ACT`, `DC.duelAct(st)`.


확률을 처음 배울 때 쓰는 수업용 게임입니다. 학생은 패드(1인 1기기), 교사는 컴퓨터.

## ⚔ 활동 2 · 눈 대결 / 활동 3 · 합 대결 (1:1, 학생끼리)
1. 학생이 수업에 들어가 **[방 만들기]** → 방 번호 3자리가 뜸. 친구는 **기다리는 방 목록**을 누르거나 방 번호를 넣어 들어감.
2. 각자 빈 표에 **칩 n개**를 놓음 (1단계: 눈 1~6, 칩 12개 / 2단계: 합 1~12, 칩 33개. 교사가 22개로 바꿀 수 있음). 상대 표는 끝날 때까지 안 보임.
3. 둘이 **번갈아 n번 굴림**. 누가 굴려도 **두 사람 표에 모두 적용**: 나온 수 칸에 남은 칩이 있으면 하나가 ✔.
4. 다 굴리면 **✔가 더 많은 사람이 승리**. 두 표와 실제로 나온 횟수를 나란히 보여 주고, [🔁 다시 하기]로 같은 친구와 또 겨룸.
- 짝이 없으면 **🤖 컴퓨터와 대결** (컴퓨터는 '고르게', '아무렇게나', '6이 좋아' 같은 전략 중 하나를 씀. 전적에는 안 들어감).
- 교사 화면 **⚔ 1:1 대결** 탭: 열린 방과 진행 상황, 학생별 승·패·무, **이긴 사람들과 진 사람들의 칩 평균 모양**, 최근 대결의 두 표.
- 새로고침해도 하던 방으로 돌아갑니다.
- **🧭 이번 판 나의 전략**: 칩을 놓기 전에 평평 · 평평 응용(1~4개 바꾸기) · 중앙 몰림 · 왼쪽 몰림 · 오른쪽 몰림 중에서 고를 수 있어요(안 골라도 됨). 교사 대결 탭에 전략별 이긴 비율이 나와요.
- 대결이 끝나면 표에 **놓친 주사위가 빨간 ✖** 로 칩 위에 쌓여요(그 칸에 칩이 모자랐던 만큼).
- **⚡ 내 차례에 저절로 굴리기**: 굴리기 화면 아래 체크하면 내 차례마다 자동으로 굴려요(2단계 33번도 빨리 끝나요).
- 교사 화면 학생 목록의 **👀(또는 이름)** 을 누르면 그 학생이 지금 보는 화면(대결 중인 두 표·차례·맞힘, 반 전체 판에 낸 칩, 최근 대결)을 볼 수 있어요. 보기만 하고 학생 화면은 바뀌지 않아요.
- **💰 포인트**(교사 대결 탭에서 켜고 끔): 처음 100점. 각자 걸 점수를 고르면 **둘 중 작은 점수**로 겨루고 **진 사람이 이긴 사람에게** 줌(비기면 그대로). 한 판 최대 30점, **같은 상대와 연속 3판**을 넘으면 그 판은 포인트 없음. 교사가 처음 지급·최대·연속 제한·개별 ±10·전체 되돌리기를 할 수 있고, 장부는 교사 화면이 원본입니다.

## 🪙 활동 1 · 칩 예측 (반 전체, 교사 진행)

### 규칙
1. 교사가 단계와 굴리는 횟수를 정하고 **[새 판 열기]**.
2. 학생은 굴리는 횟수만큼 칩을 받아(예: 30번 → 칩 30개) 각 결과가 **몇 번 나올지** 예상해서 칩을 나눠 놓고 **[제출하기]**. 마감 전에는 고쳐서 다시 제출할 수 있어요.
   - 굴리는 횟수는 교사가 1~6000번 사이로 정해요. 칩 개수는 항상 굴리는 횟수와 같아요. 많이 굴릴 때는 ＋ 한 번에 **61~600번: 10개씩, 601번 이상: 50개씩** 놓여요. 그 아래 작은 ＋1·－1 버튼으로 1개씩 세밀하게 고칠 수 있어요. 60번이 넘는 판은 점수가 커서 누적 점수에는 더하지 않아요.
3. 교사가 **[🎲 마감하고 굴리기]** → 모든 화면에서 같은 시각에 주사위가 하나씩 굴러가며 막대가 쌓입니다.
4. **점수 = 내 칩과 실제로 나온 횟수가 겹친 만큼** (결과마다 둘 중 작은 수를 더함).

| 단계 | 굴리는 것 | 칩 | 발견할 것 |
|---|---|---|---|
| 1단계 | 주사위 한 개의 눈 (1~6) | 30 또는 60 | 고르게 놓는 게 유리 (같은 정도로 일어날 것으로 기대) |
| 2단계 | 주사위 두 개의 합 (1~12, 합 1은 일어나지 않는 사건) | 36 또는 72 | 7 근처에 많이 놓는 게 유리 (경우의 수가 다름) |

## 교사 화면
- **🎲 게임**: 제출 현황 → 굴리기 → 실제 횟수 막대, 이번 판 순위와 칩 모양, 반 평균 칩 모양, 생각해 볼 질문. 이론값 점선은 처음엔 꺼져 있어요(발견 뒤에 켜기).
- **🔬 전략 대결 모의실험**: 미리 준비한 전략과 지난 판 학생들의 칩을 골라 **같은 굴림으로 1·10·100·1000판** 겨뤄 1등 횟수(승률)와 평균 점수를 비교. 한 판은 운, 많이 하면 전략 차이가 보입니다.
- **📊 아주 많이 굴려 보기**: 10~10000번씩 쌓아 상대도수가 일정한 값에 가까워지는 것 보기.
- **🧮 두 주사위 합 표**: 6×6 표에서 합이 같은 칸 칠하기.
- **📒 기록**: 학생별 누적 점수·판 수·평균·1등 횟수, 판별 결과, CSV.
- **📺 크게 보기**(Esc로 끝), **✋ 전체 멈춤**, 학생 옆 🔓(기기 바꾸기: 이름 풀어 주기), 이름 가리기.
- 점수 장부는 교사 브라우저에 저장됩니다. 같은 컴퓨터·같은 브라우저로 다시 열면 이어집니다.
